Eco Smart Bin

Intelligent Waste Management System

🚀 Our Project

Eco Smart Bin is an innovative mobile application designed to improve waste management. The system allows users to recycle waste and earn points, which can be exchanged for cash rewards. It features real-time monitoring of bins, QR code verification, and instant notifications to ensure a smooth and efficient recycling process.
